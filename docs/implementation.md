# KuraSui 第一版

用户已提供完整需求并要求直接实现。采用 React、TypeScript、Three.js/R3F、Recharts，本地浏览器持久化，中文界面。三维人体为自制几何示意，不使用外部模型或医学重建。

## 模块

- domain：记录类型、时间快照、参考范围、可比性、病灶关联、存储格式。
- data：独立的虚构记录，包含不规则日期和两个不同病灶。
- BodyModel：全身人体、器官选择、视角、透明层和二维降级。
- Dashboard：全局时间、指标、器官详情、趋势、记录与对比。
- RecordForm：数值、病灶、报告结论和个人备注，手动计算指数。
- Storage：demo/personal 两个命名空间，显示读写失败，导出、清空。

## 明确规则

单次检查模式按日期匹配；邻近模式默认仅取选定日期及此前 N 天。允许显式开启之后 N 天，但所有后续记录带标记。趋势只显示截止日期之前的记录。同名指标单位、检查方式、测量条件不同则拆成不同序列。病灶通过明确确认关联到稳定 ID。

缺失、无参考范围、范围内、超出范围、随访和超过 180 天未更新分别显示。180 天只是数据新鲜度设置，不是随访医疗建议。所有计算指数手工录入。

## 实现与验证顺序

1. 建立项目和数据规则测试，观察测试失败。
2. 实现领域与持久化逻辑，使规则测试通过。
3. 完成人体、监控台、记录表单与对比交互。
4. 运行类型检查、生产构建及浏览器验收；检查移动端与二维降级。
5. 提供运行说明、数据边界与实测结果。
