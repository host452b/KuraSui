# 第一版验收记录

日期：2026-09-30。环境：macOS、Node.js 22.14.0、本机 Google Chrome。

- `npm test`：16 项数据规则测试通过。
- `npm run test:production`：TypeScript 检查、Vite 生产构建、8 项生产浏览器验收通过。

- 已检查桌面与 390 px 手机宽度的实际截图：`artifacts/kurasui-desktop.png`、`artifacts/kurasui-mobile.png`。

浏览器验收覆盖：人体与日期联动、缺失状态、新增/编辑/持久化/导出/删除、自定义指标、病灶确认与独立比较、邻近窗口未来数据显式授权、清空后保持空白、移动端不产生整页横向溢出、无 WebGL 降级、存储失败不误报成功、旋转及视角重置。
