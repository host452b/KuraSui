# KuraSui · 身体的时间地图

一个以交互式 Three.js 人体为核心的个人健康记录应用。中文界面，React + TypeScript + Vite，浏览器本地存储。项目不包含服务器、账号或数据上传接口。

## 启动

需要 Node.js 22.12+（本项目已使用 22.14 验证）。

```bash
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。开发服务器默认仅监听本机。

```bash
npm run build        # TypeScript 检查及生产构建，输出 dist/
npm run preview      # 本机预览生产构建
npm test             # 数据与持久化规则测试
npm run test:e2e     # 独立 Chrome 中的浏览器验收
npm run test:production # 构建后，在生产预览上执行同一组浏览器验收
npm run format      # 格式化源代码
```

浏览器测试使用本机已安装的 Google Chrome，不访问个人浏览器资料。测试会自动启动开发服务器，已有服务时复用。若没有 Chrome，可安装 Playwright Chromium，并移除 playwright.config.ts 的 `channel: 'chrome'` 配置。

## 已实现

- 自制连续曲面的三维人体示意，器官可选，正背面、拖动旋转、缩放、透明层及视角重置。
- WebGL 不可用或模型加载失败时自动显示二维人体；也可以手动切换，或用 `?view=2d` 打开。
- 全身概览、脑部、甲状腺、心脏、肺部、肝脏、胃部、肾脏的记录与状态联动。
- 体重、BMI、血压、血脂、血糖、肝肾功能、肿瘤标志物等数值记录，支持自定义指标。
- 病灶部位、侧别、1–3 维尺寸、稳定 ID、原始描述及明确确认后的续录关联。
- 实测指标、手动计算指数、病灶、报告结论、个人备注的新增、编辑和删除。
- 单日检查与可设置时间窗口的邻近记录，显示每条数据的真实检查日期。
- 趋势图、任意两个检查日期的对比，以及数据来源、检查方式和测量背景。
- 示例空间与个人空间独立保存；刷新后保留，JSON 导出、单条删除和当前空间清空。
- 适配手机，横向表格与时间线独立滚动；表单使用原生对话框和键盘焦点管理。

首次打开进入虚构示例空间。切换右上角「我的数据」即可录入个人记录。示例中的数值、参考范围、病灶、报告和建议全部为虚构，不能用作个人医学判断标准。

## 数据规则

- 日期筛选使用 **检查日期**，录入时间独立保存。单次检查模式按日期匹配，同日的多条记录保留各自来源。
- 邻近窗口默认只取基准日期及此前 N 天。只有主动勾选后才包含之后 N 天，并标注“后续记录”。
- 趋势始终截止于基准日期。横轴按实际日期间隔排列；点间直线仅辅助阅读。
- 指标名称、记录类型、器官、单位、检查方式、测量条件不同时，分为不同序列，不自动换算单位。
- 同一序列同一天多条记录时，对比不擅自挑选一条计算差值，提示核对。
- 病灶 ID 不自动根据名称匹配；新观察关联已有 ID 时必须确认。器官、部位、侧别必须保持一致，尺寸维度不一致时不计算差值。
- 参考范围采用用户输入的上下限，边界包含在范围内。严格大于/小于等复杂原始范围应保存在备注中；不支持自动解析。
- 没有值或没有参考范围不会标记为正常。范围内、范围外与报告随访等状态可以同时存在。
- “较旧”表示距查看日期超过 180 天，仅描述数据新鲜度，不代表临床复查周期。
- BMI、FLI、FIB-4 等只支持手动录入已有结果，不自动计算、诊断或评分。

## 本地存储与边界

记录保存在当前浏览器、当前站点来源下的 localStorage：

- `kurasui:demo:v1`
- `kurasui:personal:v1`

不同浏览器、端口、`localhost` 与 `127.0.0.1` 是不同的存储空间。清理浏览器数据会移除记录，请定期导出 JSON。此版本不提供文件导入、账号、跨设备同步、PDF/OCR、医学影像重建或本地加密。同一站点来源下的其他脚本可读取 localStorage，个人部署请使用可信且独立的来源。

存储失败会阻止保存成功提示。读取损坏数据时保留原始内容，并支持从数据管理导出原始备份。多个页面同时编辑的冲突协调尚未实现，建议使用单个标签页管理记录。

## 三维资源与代码

`public/models/body-shell.glb` 是本项目自制的示意人体曲面，由 `scripts/generate-body.mjs` 将简单几何体的距离场融合后生成。器官、肋骨和病灶标记由 Three.js 几何体构建。没有使用外部人物素材或真实医学影像，病灶位置仅示意器官区域，不能用于定位诊疗。

```bash
node scripts/generate-body.mjs   # 重新生成自制人体外壳
```

- `src/domain.ts`：日期、参考范围、可比性、病灶与存储规则。
- `src/data.ts`：独立的虚构数据。
- `src/components/BodyModel.tsx`：三维人体与二维降级。
- `src/components/RecordForm.tsx`：健康记录录入和修改。
- `src/components/CompareDialog.tsx`：日期对比。
- `src/components/TrendChart.tsx`：按实际时间绘制的趋势。
- `src/App.tsx`：页面、全局筛选与数据空间。

技术参考：[React Three Fiber Canvas](https://r3f.docs.pmnd.rs/api/canvas)、[Recharts LineChart](https://recharts.github.io/en-US/api/LineChart/)。三维模块按需加载；Three.js/R3F 的生产包仍会触发 Vite 的默认体积提示，这是第一版的性能优化空间。
